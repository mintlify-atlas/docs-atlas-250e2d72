UDA organizes its component ecosystem into two complementary layers that together cover the full stack of a Java enterprise web application.

## Two tiers of components

### udaLib — Java server-side components

`udaLib` (published as `x38ShLibClasses`) provides the Java libraries that power the server side of a UDA application:

- **Spring MVC integration** — base controllers, request mapping helpers, and JSON serialization utilities
- **Security** — integration with HDIV and role-based access control
- **Service and DAO layers** — abstract base classes following the MVC + layered-architecture pattern
- **Validation** — server-side Bean Validation (JSR-303/349) support wired to the client-side error display
- **Exception handling** — centralized HTTP error responses in a format the RUP feedback component understands
- **i18n** — `MessageSource` helpers for returning localized messages to the browser

`udaLib` is distributed as a Maven artifact. Add it to your `pom.xml`:

```xml
<dependency>
    <groupId>com.ejie.x38</groupId>
    <artifactId>x38ShLibClasses</artifactId>
    <version>6.4.0-RELEASE</version>
</dependency>
```

### udaRUP — client-side Rich UI Pattern components

`udaRUP` is a suite of jQuery plugins that implement UDA's web UI patterns. Each plugin:

- wraps a well-established third-party library with a **standardized API**
- applies WAI-ARIA roles and keyboard navigation automatically
- communicates with the server via Ajax using the URL conventions generated by the UDA code wizard
- emits consistent events so components can be composed together (e.g., a toolbar controlling a table)

<Note>
  Download the latest RUP bundle from [GitHub Releases](https://github.com/UDA-EJIE/udaRUP/releases/tag/v6.4.0). The ZIP contains all JavaScript, CSS, and image assets.
</Note>

## Why RUP?

Writing accessible, Ajax-enabled UI from scratch is expensive and error-prone. RUP solves this by providing a single, opinionated layer on top of the JavaScript ecosystem:

| Without RUP | With RUP |
|---|---|
| Write custom DataTables config per project | `rup_table` with consistent options and events |
| Hand-roll accessible dialog markup | `rup_dialog` with ARIA roles automatically applied |
| Manually wire form submit to Ajax | `rup_form` with built-in validation and error display |
| Implement keyboard nav in every dropdown | `rup_select` / `rup_combo` out of the box |

Because every RUP component follows the same jQuery plugin convention (`$.fn.rup_<name>`), developers familiar with one component can learn any other quickly.

## Component philosophy

RUP components are **thin, standardized wrappers** around established open-source libraries:

| RUP component | Underlying library |
|---|---|
| `rup_table` | [DataTables](https://datatables.net/) |
| `rup_select`, `rup_combo` | [Select2](https://select2.org/) |
| `rup_date` | [jQuery UI Datepicker](https://jqueryui.com/datepicker/) |
| `rup_dialog` | [jQuery UI Dialog](https://jqueryui.com/dialog/) |
| `rup_accordion` | [jQuery UI Accordion](https://jqueryui.com/accordion/) |
| `rup_tabs` | [jQuery UI Tabs](https://jqueryui.com/tabs/) |
| `rup_autocomplete` | [jQuery UI Autocomplete](https://jqueryui.com/autocomplete/) |
| `rup_upload` | [jQuery File Upload](https://github.com/blueimp/jQuery-File-Upload) |

This approach means:
- Existing community documentation for the underlying library still applies.
- Security patches in upstream libraries are picked up when UDA updates.
- Developers are not locked into a proprietary API.

## Quick reference: RUP components

| Component | Purpose | Key dependency |
|---|---|---|
| `rup_table` | Paginated, sortable, filterable data tables | DataTables |
| `rup_form` | Form handling with Ajax submit and validation | jQuery |
| `rup_select` | Single/multi-select dropdown with remote data | Select2 |
| `rup_combo` | Cascading combo-box | Select2 |
| `rup_autocomplete` | Typeahead text input with Ajax source | jQuery UI |
| `rup_date` | Date picker, date range, and time picker | jQuery UI |
| `rup_menu` | Horizontal, vertical, and breadcrumb menus | jQuery UI |
| `rup_tabs` | Tab panel | jQuery UI |
| `rup_accordion` | Collapsible accordion panels | jQuery UI |
| `rup_dialog` | Modal dialog | jQuery UI |
| `rup_feedback` | Status messages: success, error, processing | jQuery |
| `rup_toolbar` | Button toolbar with standard CRUD actions | jQuery |
| `rup_upload` | File upload | jQuery File Upload |
| `rup_wizard` | Multi-step form wizard | jQuery |
