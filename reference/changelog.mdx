## UDA 6.x

**Current series.** Actively developed and supported.

### Highlights

- **Eclipse 2024-06 support** — The bundled Eclipse installation now uses the 2024-06 release train, bringing a modern IDE baseline and updated Java tooling.
- **Updated RUP components** — The udaRUP JavaScript and CSS library has been modernized with dependency updates and accessibility improvements.
- **Enhanced Spring Boot compatibility** — Application templates and shared libraries have been updated for better alignment with current Spring Boot versions.
- **Improved code generation** — The Eclipse plugin wizards generate cleaner, more idiomatic Spring MVC and REST controller code.

### Releases in this series

| Version | Date | Notes |
|---------|------|-------|
| 6.4.0 | December 16, 2025 | Current stable release |
| 6.3.0 | October 15, 2024 | Previous stable |

## UDA 5.x

**Maintenance series.** Security fixes only; no new features.

### Highlights

- **HDIV security integration** — The udaHdiv module provides integration with the HDIV (HTTP Data Integrity Validator) framework for protection against common web vulnerabilities.
- **Improved accessibility** — Components updated to better comply with WCAG 2.0 and WAI-ARIA standards.
- **Spring 5.x support** — Libraries and templates updated for compatibility with the Spring Framework 5.x generation.

### Releases in this series

| Version | Date | Notes |
|---------|------|-------|
| 5.4.2 | January 21, 2025 | Latest maintenance release |

---

## UDA 4.x

**Legacy series.** No longer supported.

### Highlights

- **Eclipse 2020-03 compatibility** — The legacy Eclipse bundle is based on the 2020-03 release train.
- **Stable CRUD scaffolding** — Mature code generation for form-based maintenance interfaces.
- **Long-term reference** — Existing 4.x applications continue to function; no further updates will be made.

<Warning>
  UDA 4.x has reached end of life. No bug fixes, security patches, or new features will be released. Plan your migration to UDA 6.x.
</Warning>

### Releases in this series

| Version | Date | Notes |
|---------|------|-------|
| 4.5.4 | September 30, 2025 | Final 4.x release |
