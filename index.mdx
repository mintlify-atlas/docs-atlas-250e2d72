UDA (Utilidades de Desarrollo de Aplicaciones) is an open-source toolkit developed by [EJIE](https://github.com/UDA-EJIE) that significantly accelerates enterprise Java application development. It automates repetitive, low-value tasks — such as scaffolding CRUD interfaces and generating layered MVC code — so you can focus on building business logic.

## What UDA provides

UDA bundles everything you need to build production-ready Java web applications:

<CardGroup cols={3}>
  <Card title="Eclipse Plugin" icon="plug" href="/guides/code-generation">
    Generate complete project scaffolding, controllers, services, and CRUD interfaces directly from Eclipse wizards.
  </Card>
  <Card title="RUP Components" icon="table-columns" href="/components/rup-components">
    A rich library of accessible, Ajax-enabled UI components — tables, forms, date pickers, menus, and more.
  </Card>
  <Card title="Maven Libraries" icon="book" href="/architecture/layers">
    Java shared libraries (`x38ShLibClasses`) with base classes and utilities for controllers, services, and DAOs.
  </Card>
  <Card title="Project Templates" icon="file-code" href="/guides/code-generation">
    Pre-configured Maven archetypes with Spring MVC wiring, security integration, and best-practice structure.
  </Card>
  <Card title="UI Patterns" icon="desktop" href="/components/ui-patterns">
    Ready-to-use patterns for maintenance forms, master-detail views, search tables, and more.
  </Card>
  <Card title="Accessibility" icon="universal-access" href="/components/accessibility">
    Built-in WCAG 2.0 and WAI-ARIA compliance across all generated interfaces and components.
  </Card>
</CardGroup>

## Get started

<Steps>
  <Step title="Install prerequisites">
    Install Java 8+, Eclipse IDE, and Maven 3.x on your development machine.
  </Step>
  <Step title="Install the UDA plugin">
    Download the latest UDA plugin and templates from the [releases page](/reference/versions) and install them into Eclipse.
  </Step>
  <Step title="Generate your first project">
    Use the **New UDA Project** wizard in Eclipse to scaffold a complete layered application with Spring MVC, persistence, and a web module.
  </Step>
  <Step title="Add CRUD interfaces">
    Run the **Maintenance Assistant** to generate full CRUD forms, tables, and REST endpoints for any domain entity in minutes.
  </Step>
</Steps>

<Note>
  The latest stable release is **UDA 6.4.0** (December 2025). See the [versions page](/reference/versions) for all available downloads.
</Note>
